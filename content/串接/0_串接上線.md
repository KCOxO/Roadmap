⚠️ 現在在 Obsidian 寫作時，必須注意的 3 個小細節

為了讓您的筆記在未來上傳到 GitHub 轉成網頁時「完全不破圖、不跑版」，請從今天開始保持以下習慣：

1. **圖片路徑設定（非常重要）**：  
    進入 Obsidian 設定 ➡️ `Files and links`（檔案與連結）➡️ 將 `Default location for new attachments`（新附件的預設位置）改為 `In subfolder under current folder`（目前資料夾底下的子資料夾），並將子資料夾命名為 `assets` 或 `images`。這樣未來 GitHub 讀取圖片時才不會找不到檔案。
2. **連結格式設定**：  
    在同一個設定頁面中，將 `New link format`（新連結格式）設定為 `Absolute path in vault`（儲存庫中的絕對路徑）或 `Relative path to file`（相對於檔案的相對路徑），這能確保網頁版跳轉連結時百分之百正常。
3. **注意隱私（筆記分流）**：  
    您可以在 Obsidian 內開一個獨立的資料夾叫做 `00_公開學習歷程`。平常日記、個人隱私寫在其他資料夾，只有要分享出去的成果才放進這個資料夾。未來設定 GitHub 時，**只同步這個公開資料夾**即可。
