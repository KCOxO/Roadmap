🛠️ 步驟 1：安裝兩大核心工具（環境建置）

Quartz 需要依靠 `Node.js`（執行環境）與 `Git`（上傳工具）才能運作。請依你的作業系統（以 Windows 為主）下載並安裝：

1. **安裝 Node.js**：前往 [Node.js 官方網站](https://nodejs.org/)，下載並安裝 **LTS（長期維護）版本**。安裝時一路點「下一步」到底即可。
2. **安裝 GitHub Desktop**：前往 [GitHub Desktop 官網](https://desktop.github.com/) 下載安裝，並登入你的 GitHub 帳號。這能讓你免去背誦複雜的 Git 指令。

---

📂 步驟 2：在 GitHub 上建立你的網站倉庫

我們要先在 GitHub 雲端挖一個專門放你網頁的空間。

1. 登入 [GitHub 網站](https://github.com/)。
2. 點擊右上角的 **「+」** ➔ 選擇 **New repository（新增倉庫）**。
3. 設定資訊：
    - **Repository name**：輸入你想要的專案名稱（例如 `my-learning-garden`）。
    - **Public/Private**：必須選擇 **Public（公開）**，未來 GitHub 才能幫你轉成公開網頁。
    - **不要勾選** Add a README file。
4. 點擊最下方的 **Create repository**。畫面會跳轉到一個充滿程式碼的頁面，**先放著不要關閉**。

---

💻 步驟 3：用終端機下載 Quartz 模板

別擔心，跟著我複製貼上這三行指令就好！

1. 在 Windows 搜尋列輸入 `cmd`，打開 **命令提示字元（終端機）**。
2. 輸入以下指令並按 Enter（這會把你的終端機位置移動到桌面，方便操作）：
    
    bash
    
    ```
    cd Desktop
    ```
    
    請謹慎使用程式碼。
    
3. 複製並貼上這行官方指令（這會用 Node.js 下載最新的 Quartz 4 系統，並在桌面建立一個名為 `quartz` 的資料夾）：
    
    bash
    
    ```
    npx quartz create
    ```
    
    請謹慎使用程式碼。
    
4. 執行過程中，畫面上會出現選單，請用鍵盤上下鍵選擇：
    - `🎨 Setup Paths` ➔ 選擇 **Empty Quartz**（建立全新的空網站）。
    - `📋 Link Type` ➔ 選擇 **Treat links as Shortest Path**（這與 Obsidian 的預設連結格式最相容）。

---

🔄 步驟 4：將 Obsidian 筆記連動到 Quartz

此時你的桌面上會多出一個 `quartz` 資料夾。請打開它，你會看到裡面有一個名為 **`content`** 的子資料夾。

- **關鍵操作**：未來你寫的所有 SQL 學習歷程筆記（包含 `.md` 檔案和你的圖片資料夾），**都必須直接存在這個 `content` 資料夾裡面**。
- **如何用 Obsidian 開啟**：打開你的 Obsidian 軟體 ➔ 選擇「開啟現有儲存庫（Open folder as vault）」 ➔ 選取桌面上的這個 **`quartz` 資料夾**。這樣你就能直接在裡面一邊寫筆記，一邊準備發布。

---

🚀 下一步：我們來測試「本機預覽」

請將我們上次寫的那篇 **SQL 基礎實戰筆記**（包含正確的 `---` 標籤屬性區），存入 `content` 資料夾中。

完成上述步驟後，請在終端機（cmd）中輸入以下兩行指令：

bash

```
cd quartz
npx quartz build --serve
```

請謹慎使用程式碼。

畫面會出現一行綠色的網址 `http://localhost:8080`。請在瀏覽器打開它，看看你人生中第一個 Quartz 網頁有沒有成功顯示出來！

如果你在安裝軟體、或是執行 `npx quartz create` 時**畫面的哪一行卡住了、或者跳出紅色錯誤訊息**，請立刻複製貼上告訴我，我來幫你看看是哪裡不對！
