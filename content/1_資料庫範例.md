# 📊 SQL Server 基礎實戰：電商訂單數據分析


## 🎯 學習目標
掌握 T-SQL 的基礎查詢、多表聯查（JOIN）與數據分組統計（GROUP BY）。

---

## 🛠️ 步驟 1：基礎資料查詢 (SELECT)
**【目標】** 確認客戶資料表（Customers）的欄位結構與內容。

```sql
-- 查詢所有住在台北的客戶
SELECT CustomerID, Name, City 
FROM Customers
WHERE City = 'Taipei';
```

### 🖥️ 預期執行結果

| CustomerID | Name | City   |
| :--------- | :--- | :----- |
| 1          | 張小明  | Taipei |
| 2          | 李媽媽  | Taipei |

---

## 🔗 步驟 2：多表跨庫聯查 (INNER JOIN)
**【目標】** 客戶表只有名字，訂單表只有金額。我們需要將兩張表串聯，抓出「每筆訂單是哪個客戶買的、花了多少錢」。

```sql
-- 透過 CustomerID 串聯兩張表，並撈出訂單金額
SELECT 
    c.Name, 
    o.OrderID, 
    o.OrderDate, 
    o.TotalAmount
FROM Customers c
INNER JOIN Orders o ON c.CustomerID = o.CustomerID;
```

### 🖥️ 預期執行結果

| Name | OrderID | OrderDate | TotalAmount |
| :--- | :--- | :--- | :--- |
| 張小明 | 1001 | 2026-03-01 | 1500 |
| 張小明 | 1002 | 2026-03-05 | 2300 |
| 李媽媽 | 1003 | 2026-03-06 | 800 |

---

## 📈 步驟 3：數據分組與統計 (GROUP BY & SUM)
**【目標】** 成果驗收！計算「每位台北客戶在店裡的**消費總金額**」，並由高到低排序。

```sql
-- 結合 JOIN 與 GROUP BY 進行加總統計
SELECT 
    c.Name, 
    COUNT(o.OrderID) AS 總訂單數,
    SUM(o.TotalAmount) AS 總消費金額
FROM Customers c
INNER JOIN Orders o ON c.CustomerID = o.CustomerID
WHERE c.City = 'Taipei'
GROUP BY c.Name
ORDER BY 總消費金額 DESC;
```

### 🖥️ 預期執行結果

| Name | 總訂單數 | 總消費金額 |
| :--- | :--- | :--- |
| 張小明 | 2 | 3800 |
| 李媽媽 | 1 | 800 |

---

## 💡 本章學習心得
1. `INNER JOIN` 的關鍵在於找到兩張表的「橋樑欄位」（此處為 `CustomerID`）。
2. 使用 `GROUP BY` 時，`SELECT` 後方除了聚合函數（如 `SUM`, `COUNT`）之外的欄位，都必須放到 `GROUP BY` 後面，這是初學 T-SQL 最容易出錯的地方！
